# นำ workflow จาก glass มาใช้ใน sport

วันที่: 30 กันยายน 2026

## เป้าหมาย

ให้หน้าใน `sport` เดินขั้นตอนเดียวกับ workflow ของ `glass` ทั้งสมาชิก กิจกรรม ค่ายเกม และหวย หน้าตายังเป็น Orange Light Solid ตาม `sport/design.md` และคลาสที่มีอยู่ (`soft-card`, `soft-panel`, `soft-btn-primary`, `soft-btn-outline`, `SubPageShell`, ตัวแปรใน `sport/app/globals.css`)

ข้อมูลธุรกรรมเป็นค่าจำลองในเบราว์เซอร์ จุดเดียวที่เรียกเครือข่ายคือ `POST /api/auth/login`

## สถาปัตยกรรม

หน้าย่อยใช้ `SubPageShell` แผงซ้อนใช้กรอบเดียวกับกล่องล็อกอินปัจจุบัน (เต็มความกว้างชิดล่างบนมือถือ เป็นกล่องกลางบน `sm`) แยกเป็นคอมโพเนนต์ร่วมชื่อ `SheetFrame` ให้สมัคร ฝาก ถอน และรายละเอียดธุรกรรมเรียกใช้ บนจอกว้างหน้าเดียวกันยืดเป็นกริด ไม่มีโมดัลฮับเดสก์ท็อป

`MemberProvider` ครอบแอปใน `sport/app/layout.tsx` ทุกหน้าอ่านและเขียนผ่านฮุค `useMember()`

โฟลเดอร์คอมโพเนนต์ใหม่ใต้ `sport/components/`: `member`, `auth`, `wallet`, `activities`, `check-in`, `commission`, `shop`, `promotions`, `referral`, `vip`, `profile`, `wheel`, `games`, `lottery`

ข้อมูลคงที่เพิ่มใน `sport/data/` หน้าที่มีอยู่เหลือหน้าที่ประกอบคอมโพเนนต์เหล่านี้ ทางลัดเดิมยังชี้หน้าจริง: `/affiliate` และ `/invite` ไป `/referral`, `/rebate` ไป `/commission`, `/events` ไป `/activities`, `/rank` ไป `/vip`, `/diamond-shop` ไป `/shop`, `/promotion` ไป `/promotions`, `/checkin` ไป `/check-in`

## การไหลของข้อมูล

ค่าเริ่มต้นมาจาก `sport/data/member.ts` แล้วทับด้วย `sessionStorage` คีย์ `sport-member-v1` เมื่อคีย์นั้นอ่านไม่ได้หรือ JSON พัง ให้ทิ้งแล้วใช้ค่าเริ่มต้น หน้ายังเปิดได้

ฟิลด์ใน provider:

- ผู้ใช้: ชื่อที่แสดง, ชื่อบัญชี, เบอร์, รหัสผ่านจำลอง, สถานะล็อกอิน
- กระเป๋า: ยอดบาท, เพชร, ตั๋ววงล้อ, สวิตช์รับโปรโมชั่น, ยอดรายได้ชวนเพื่อนที่ถอนได้
- บัญชีธนาคาร และรหัสบัญชีหลักที่ใช้ถอน
- ประวัติธุรกรรม, รายการรับคืนยอด, สลิปหวย, รหัสเกมที่กดหัวใจ, โควตาแลกเพชรของวันนี้

รหัสผ่านเริ่มต้นในข้อมูลสมาชิกคือ `demo1234` ใช้ตรวจตอนเปลี่ยนรหัสเท่านั้น ไม่ส่งไปกับล็อกอิน API

สถานะขั้นของหน้า (ขั้นฝาก แท็บที่เปิด ช่องค้นหา มุมวงล้อ) อยู่ในหน้านั้น พอรีเฟรชกลับไปจุดเริ่มของหน้า ยอดและประวัติยังอยู่

ค่าคงที่อ่านอย่างเดียวอยู่ใน `sport/data/`: ช่องทางฝาก บัญชีรับโอน รหัสคูปอง กิจกรรม วันเช็คอิน อัตราคืนยอด แพ็กเกจเพชร โปรโมชั่น ตารางแนะนำเพื่อน แรงค์ VIP ส่วนวงล้อ ตลาดหวย รอบ และเกมรายค่าย ผลจากการกดเขียนกลับเข้า provider

ล็อกอินสำเร็จจาก API แล้วตั้งชื่อผู้ใช้และสถานะล็อกอินใน provider สมัครและธุรกรรมที่เหลืออัปเดต provider อย่างเดียว

## กฎฟอร์มร่วม

- เบอร์โทร: ตัวเลข 10 หลัก
- รหัสผ่าน: 6–32 ตัวอักษร
- ชื่อและนามสกุล: ไม่ว่าง และไม่เกิน 40 ตัวอักษรต่อช่อง
- เลขบัญชี: ตัวเลข 10–12 หลัก
- จำนวนเงิน: ตัวเลขไม่เกิน 9 หลัก และมากกว่า 0
- ปุ่มกดสูงอย่างน้อย `h-10` หน้าเริ่มจากมือถือแล้วค่อยขยายด้วย `sm:` `md:` `lg:`

## สมัครและกระเป๋า

### สมัคร

แผงสองขั้น ขั้นที่ 1 กรอกเบอร์ รหัสผ่าน และยืนยันรหัส ผ่านเกณฑ์แล้วไปขั้นที่ 2 ชื่อ นามสกุล เลขบัญชี เลือกธนาคารจากรายการในข้อมูล และช่องทางที่รู้จัก กดย้อนกลับได้ ยืนยันแล้วเก็บชื่อที่แสดง เบอร์ และรหัสผ่านใน provider ปิดแผง และอยู่ที่หน้าหลัก ช่องที่ไม่ผ่านเกณฑ์อยู่ที่ขั้นเดิมและแสดงข้อความในแผง

### ล็อกอิน

แผงเดิมยิง `POST /api/auth/login` สำเร็จแล้วเก็บชื่อผู้ใช้ใน provider เซิร์ฟเวอร์ตอบไม่สำเร็จแสดงข้อความจาก API ต่อไม่ติดแสดงว่าเชื่อมต่อไม่ได้ และไม่ตั้งชื่อผู้ใช้

### ฝาก

สามขั้นในแท็บฝากของ `/wallet`

1. เลือกช่องทาง: บัญชีธนาคาร, Payment Gateway, ทรูวอลเล็ท เลือกธนาคารแล้วไปขั้นที่ 2 อีกสองช่องทางแสดงว่ายังไม่เปิดให้บริการและอยู่ที่ขั้นที่ 1
2. แสดงบัญชีรับโอนจากข้อมูลจำลอง มีปุ่มคัดลอกเลขบัญชี เลือกยอดด่วนหรือกรอกเอง ยอดไม่ผ่านเกณฑ์ไปขั้นที่ 3 ไม่ได้
3. สรุปยอด เลือกไฟล์สลิปแล้วเก็บชื่อไฟล์ ยืนยันแล้วบวกยอดบาท เพิ่มประวัติชนิดฝากสถานะสำเร็จ และกลับไปขั้นที่ 1

### ถอน

อยู่ในแท็บถอน เลือกได้เฉพาะบัญชีสถานะตรวจแล้ว ใส่ยอดหรือกดถอนทั้งหมดซึ่งเติมเท่าคงเหลือ ไม่มีบัญชีที่ตรวจแล้ว ยอดว่าง หรือยอดเกินคงเหลือ ปุ่มยืนยันกดไม่ได้ สำเร็จแล้วหักยอดและเพิ่มประวัติชนิดถอนสถานะสำเร็จ

### คูปอง

แท็บใน `/wallet` กรอกรหัสไม่เกิน 20 ตัวอักษร

| รหัส | ผล |
|---|---|
| `SPORT100` | บวก 100 บาท |
| `FREEGEMS` | บวก 50 เพชร |
| `WELCOME50` | บวก 50 บาท |

ช่องว่างแสดงให้กรอกรหัส รหัสอื่นแสดงว่ารหัสไม่ถูกต้องหรือหมดอายุ ยอดไม่เปลี่ยน

### ประวัติ

แท็บชนิด: ฝาก, ถอน, โปรโมชั่น, เดิมพัน กรองวันเริ่มและวันสิ้นสุด แสดง 10 แถวต่อหน้า ข้อมูลเริ่มต้นมีอย่างน้อยหนึ่งแถวสถานะรอดำเนินการ แถวนั้นกดแล้วเปิด `SheetFrame` แสดงชนิด จำนวน เวลา และสถานะ ฝากและถอนที่เพิ่งสำเร็จถูกเพิ่มเป็นสถานะสำเร็จ

## กิจกรรมและรางวัล

### กิจกรรม

`/activities` กรองหมวดจากข้อมูล เปิดรายการแล้วแสดงรายละเอียดในหน้าเดียวกัน: ความคืบหน้าเทิร์นเทียบเป้า ตารางระดับ และปุ่มรับรางวัล ข้อมูลเริ่มต้นมีอย่างน้อยหนึ่งรายการที่เทิร์นถึงเป้า และหนึ่งรายการที่ยังไม่ถึง ถึงเป้าแล้วกดรับได้ครั้งเดียว รับแล้วบวกบาทตามตัวเลขรางวัลของรายการนั้นและติดสถานะรับแล้ว รายการที่ยังไม่ถึงเป้าปุ่มรับกดไม่ได้

### เช็คอิน

ปฏิทิน 7 วันจากข้อมูล วันนี้รับได้ครั้งเดียว รับแล้วบวก 5 เพชร วันที่ทำเครื่องหมายพิเศษใช้จำนวนเพชรตามข้อมูลของวันนั้น ปุ่มวันที่รับแล้วกดไม่ได้

### คืนยอด

`/commission` สองแท็บ คืนยอดเล่นและคืนยอดเสีย แต่ละแท็บแสดงอัตรา ขั้นต่ำ และยอดที่รับได้จากข้อมูล ข้อมูลเริ่มต้นให้คืนยอดเล่นอยู่เหนือขั้นต่ำ และคืนยอดเสียอยู่ต่ำกว่าขั้นต่ำ ยอดต่ำกว่าขั้นต่ำปุ่มรับกดไม่ได้ รับแล้วบวกบาท ศูนย์ยอดที่รับได้ของแท็บนั้น และเพิ่มแถวในรายการรับล่าสุด

### ร้านเพชร

การ์ดยอดเพชร แพ็กเกจ และข้อกำหนดแบบพับได้ เพชรไม่พอหรือโควตาวันนี้ครบ 3 ครั้ง แลกไม่ได้ สำเร็จแล้วหักเพชร บวกเครดิตบาท และเพิ่มโควตาวันนี้หนึ่งครั้ง

### วงล้อ

`/wheel` เลือกจ่ายด้วยตั๋ว 1 ใบหรือเพชร 50 เม็ดต่อการหมุน ข้อมูลเริ่มต้นมีตั๋ว 1 ใบ หมุนได้ครั้งละหนึ่ง ระหว่างหมุนปุ่มหมุนถูกปิด จบแล้วแสดงชื่อรางวัล หักต้นทุน บวกรางวัลถ้าเป็นบาทหรือเพชร และเพิ่มแถวประวัติกับรายชื่อผู้ชนะล่าสุด ตั๋วหรือเพชรไม่พอหมุนไม่ได้

## โปรไฟล์สมาชิก

### โปรโมชั่น

กรองหมวดทั่วไปและพิเศษ เปิดรายละเอียดในแผงของหน้า ปุ่มรับโปรไปที่ `/wallet?tab=deposit` สวิตช์เปิดรับโปรเก็บใน provider

### ชวนเพื่อน

สามแท็บ

- ภาพรวม: สามขั้นวิธีใช้ ลิงก์แนะนำ และปุ่มคัดลอก
- เพื่อนที่แนะนำ: ช่องค้นชื่อ กรองแถวที่ชื่อมีคำนั้น
- รายได้: ตัวกรองวันนี้ สัปดาห์ก่อน เดือนก่อน หรือทั้งหมด ตัดเฉพาะแถวในตารางตามวันที่ของแถว ยอดที่ถอนได้เป็นก้อนเดียวใน provider ไม่ถูกตัวกรองตัด ถอนได้เมื่อยอดนั้นมากกว่า 0 แล้วบวกเข้าบาทและศูนย์ยอดที่ถอนได้

### VIP

สามแท็บ ระดับของฉันแสดงแรงค์ปัจจุบันและแถบความคืบหน้าเทิร์นไปแรงค์ถัดไป แร็งค์เลื่อนดูแต่ละขั้นทีละใบ สิทธิประโยชน์เป็นตารางเปรียบเทียบแคชแบ็กและเงื่อนไขของทุกแรงค์

### โปรไฟล์

แท็บข้อมูลส่วนตัวแก้ LINE กับวันเกิดแล้วเก็บใน provider แท็บบัญชีเพิ่มบัญชีเมื่อเลขบัญชีผ่านเกณฑ์และเลือกธนาคารแล้ว ตั้งบัญชีหลักได้ทีละบัญชี แท็บรหัสผ่านต้องกรอกรหัสเดิมให้ตรงรหัสที่จำลองไว้ รหัสใหม่ผ่านเกณฑ์ และรหัสยืนยันตรงกัน จึงเปลี่ยนรหัส ออกจากระบบล้างสถานะล็อกอินและชื่อผู้ใช้ใน provider ยอดเงินยังอยู่

## ค่ายเกม

หมวดบนหน้าหลักพาไปหน้ารวมค่ายของหมวดนั้น การ์ดค่ายไป `/{หมวด}/[provider]`

ในค่ายมี breadcrumb กลับหน้ารวมค่าย ช่องค้นชื่อเกม แท็บตัวกรองทั้งหมด มาแรง มาใหม่ โปรด และกริดเกม กริดบนมือถือเป็น 3 คอลัมน์ แล้วขยายตาม `sport/design.md` กดหัวใจแล้วเก็บรหัสเกมใน provider เกมนั้นปรากฏในแท็บโปรดของหน้าหลัก เปิดเกมแล้วขึ้นแผงว่ากำลังเข้าเกมจำลอง

รหัสค่ายที่ไม่มีในข้อมูลของหมวดนั้น แสดงว่าไม่พบค่ายและมีลิงก์กลับหน้ารวมค่าย

## หวย

ฮับแยกกลุ่มตลาดทั่วไป รัฐบาล และยี่กี ตลาดทั่วไปเข้า `/lottery/[marketId]` แล้วเลือกวันรอบไปหน้าแทง รัฐบาลและยี่กีใช้เส้นทางของตัวเอง

หน้าแทงลำดับเดียวกันทุกตลาด: เลือกประเภทการแทง กดเลขจากแป้นหรือกริด ตั้งราคาต่อรายการ รายการเข้าสลิป แก้ราคาหรือลบรายการได้ ยืนยันได้เมื่อสลิปมีอย่างน้อยหนึ่งรายการและผลรวมไม่เกินยอดบาท ยืนยันแล้วหักเงิน เก็บสลิปใน provider สถานะบันทึกแล้ว และมีลิงก์ไป `/lottery/slips` หน้ารายการสลิปกดเข้า `/lottery/slips/[slipId]` เพื่อดูเลข ราคา และยอดรวม

ยี่กีมีแถบสลับรอบและแผงวิธีแทงห้าขั้นเพิ่มจากหน้าแทงทั่วไป

รหัสตลาดหรือรอบที่ไม่มีในข้อมูล แสดงว่าไม่พบรอบและมีลิงก์กลับ `/lottery`

## เมื่อทำไม่สำเร็จ

จุดที่กดแล้วยังไม่ผ่านแสดงข้อความในแผงของหน้านั้น และไม่เขียนยอดใน provider รายการเงื่อนไขอยู่ในการอธิบายแต่ละหน้าด้านบน รวมถึงหน้าค่ายและรอบหวยที่หาไม่เจอ

## การตรวจ

`sport` ไม่มีตัวรันเทสอัตโนมัติ แต่ละชุดที่ลงมือจบด้วยคำสั่งนี้ในโฟลเดอร์ `sport` และต้องผ่านทั้งคู่:

- `pnpm lint`
- `pnpm build`

จากนั้นเดินหน้าจอโดยยืนยันว่ายอดใน provider เปลี่ยนตรงกับที่กด และข้อความผิดเงื่อนไขโผล่โดยยอดไม่ขยับ:

1. สมัครด้วยเบอร์ไม่ครบ แล้วทำให้ครบสองขั้น ล็อกอินด้วยบัญชีที่ API รับ และลองกรณีต่อไม่ติด
2. ฝากธนาคารจนแนบสลิป ลอง Payment Gateway ถอนเกินยอด แล้วถอนได้จริง คูปอง `SPORT100` และรหัสผิด
3. ประวัติกรองชนิดกับช่วงวัน และเปิดรายการรอดำเนินการ
4. กิจกรรมรับรางวัลเมื่อถึงเป้า เช็คอินซ้ำไม่ได้ คืนยอดต่ำกว่าขั้นต่ำรับไม่ได้ ร้านเพชรครบ 3 ครั้งแลกไม่ได้ วงล้อหมุนจนตั๋วไม่พอ
5. โปรโมชั่นเปิดรายละเอียดแล้วไปแท็บฝาก ชวนเพื่อนครบสามแท็บและถอนรายได้ VIP เลื่อนแรงค์ โปรไฟล์เพิ่มบัญชีกับเปลี่ยนรหัส
6. หมวดหน้าหลักเข้าหน้ารวมค่าย เข้าค่ายที่มีอยู่ ค้นเกม กดหัวใจ เปิดรหัสค่ายที่ไม่มี
7. ฮับหวยเข้าตลาดทั่วไป รัฐบาล และยี่กี ใส่เลขลงสลิป ยืนยันเมื่อเงินพอ เปิดโพย แล้วเปิดรอบที่ไม่มี

การตรวจหน้าตา: ใช้คลาส soft และ `SubPageShell` ไม่มีสีพื้น cosmic หรือแผงแก้วจาก `glass`

## ลำดับลงมือ

สเปกนี้เป็นฉบับเดียว แผนลงมือแยกเป็นห้าชุดตามลำดับ เพื่อให้แต่ละแผนตรวจได้จบชุด:

1. `MemberProvider`, `SheetFrame`, สมัคร, ล็อกอิน, ฝาก, ถอน, คูปอง, ประวัติ
2. กิจกรรม, เช็คอิน, คืนยอด, ร้านเพชร, วงล้อ
3. โปรโมชั่น, ชวนเพื่อน, VIP, โปรไฟล์
4. หน้ารวมค่ายและกริดเกมในค่าย พร้อมทางเข้าจากหน้าหลัก
5. หวยทั้งฮับ หน้าแทง และสลิป
